Found in the lattice of the outside of a [[Ying World]]

> This is a 7x7x7 maze.
>
> At the end is a Pink Ring Device that you can use to exit the Ying World. The exit block is solid green.
>
> If you have not done a maze like this before, a standard technique is to drop a marker to indicate that a path is a dead end. In the end, the path that remains will lead to the exit. Remember that you can drop a marker by pressing M (and if you hold M for one second, that will drop a permanent marker).
